Named, triggerable functions — high-leverage things Claude can actually go do. Separate from the reflective "Singularities" sheet under Temple of Time; this one is about execution, not reflection.

How Trigger actually works: clicking it sets status to "Requested" and timestamps it — a real, visible signal, not a simulation. It does not make Claude start working instantly in the background: Claude only runs during an active Claude Code session. The next time you're talking to Claude, mention it (or Claude can check this list) and it'll pick up anything marked Requested. If you want a triggered function to actually run unattended on a schedule, ask for that separately — it's a bigger step (autonomous browser automation against real sites) worth its own explicit go-ahead.
